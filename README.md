Репозиторий содержит два файла: таблицу LibreOffice в формате ods, в которую сотрудник записывает количество клиентов с тем или иным провайдером домашнего интернета, а также наличием у него камеры видеонаблюдения и макрос для этого файла в формате bas. 

Для начала работы необходимо импортировать макрос в файл через меню "Сервис" -> "Макросы" и назначить его на открытие файла в том же меню. При первом запуске макрос запомнит нынешнюю дату и заархивирует ее. При смене даты, макрос сохранит статистику во второй лист, очистит поля и обновит дату. Таким образом происходит ежедневный учет и ведение статистики, которая сохраняется в отдельной таблице.
